# Lamoda Monitor

Сервис мониторинга наличия товаров в избранном Lamoda. Проект автоматически
проверяет страницы каталога и отправляет уведомление в Discord, когда нужный
товар или размер снова появляется в продаже.

## Решаемая задача

Ручная проверка ограниченных коллекций занимает много времени и не позволяет
быстро реагировать на возврат товара. Монитор сокращает задержку между
появлением товара и уведомлением пользователя.

## Возможности

- последовательный обход страниц избранного;
- извлечение карточек товаров и доступных размеров;
- отслеживание изменения статуса наличия;
- Discord-уведомления с названием, ценой, размерами и ссылкой;
- поддержка прокси и пользовательских HTTP-заголовков.

## Схема работы

```text
Lamoda wishlist
      |
      v
HTTP-монитор -> разбор данных товара -> проверка наличия
                                      |
                                      v
                              Discord webhook
```

## Стек

Python, Requests, JSON, Discord Webhooks.

## Конфигурация

Перед запуском необходимо указать:

- URL Discord webhook;
- Cookie и User-Agent активной сессии;
- число страниц избранного;
- прокси, если они используются.

Секреты и данные сессии не следует добавлять в Git.

## Статус

Прикладной проект 2023 года. Структура страниц и способы авторизации Lamoda
могли измениться, поэтому перед повторным запуском потребуется проверить
селекторы и формат данных.
